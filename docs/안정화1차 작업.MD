# 안정화 1차 작업

작업일: 2026-10-20

## 주요 변경

- **UI 반영:** `simsaimdang-2026-10-19_UI`의 문구와 CSS를 메인 화면에 항목별로 반영했다. 메인의 기존 기능과 시안에서 사라진 두 곳의 현행 동작은 유지했다.
- **사업·위원·평가 화면:** 사업등록에서 평가일을 선택하면 날짜 선택을 마치고 다음 입력칸으로 이동한다. 위원 통화완료 저장 후 스크롤 위치를 복원한다. 참석을 확정한 평가위원은 재로그인 시 참석확인 화면을 건너뛴다. 점수 입력칸은 방향키로 이동할 수 있다. 결과 화면의 최종 제출 시각은 한국 날짜·시간으로 표시한다.
- **표시 오류:** 총괄관리자 자료 화면에서 업체 코드 뒤에 `사`가 중복 표시되지 않도록 수정했다. 평가항목 화면은 실제 상태 조회 전 시안 평가표 대신 로딩 안내를 보여준다.
- **제안요청서·제안서 화면:** `요약 중`을 `분석 중`으로, `목차 확인`을 `파싱 결과 확인`으로 바꾸고, 요구사항 미리보기 제목을 `요구사항 확인`으로 정리했다. 제안서 안내 문구에서 HWP·PPTX를 삭제했다. 제안서 업로드에는 전송률과 등록 처리 상태를 표시한다.
- **등록 자료 영역:** 제안요청서 파일이 있으면 기존 `더 보기` 내용을 항상 표시하고, 파일이 없으면 영역을 숨긴다. 별도 `요구사항 확인` 버튼은 제거했다. 추출된 사업 현황을 이 영역에 표시한다.
- **요구사항 비교:** `FUN-1`처럼 자릿수가 짧은 번호와 `요구사항 번호` 표기를 인식하도록 추출 규칙을 보완했다. 삭제된 제안요청서 자료는 비교 화면과 분석 대상에서 제외하고, 화면을 즉시 다시 읽는다.
- **파일 삭제·업체 재등록:** 파일 삭제 시 다른 등록 건이나 결과 자료가 참조하지 않는 원본 BLOB을 삭제한다. 삭제 사유와 파싱 이력은 보존한다. 같은 이름의 삭제된 업체를 다시 등록하면 기존 업체 ID를 복원하고 새 제안서는 새 버전으로 등록할 수 있게 했다.
- **평가항목 AI 초안:** 생성 요청 직후부터 요구사항 분석·평가항목 생성 단계를 안내하고, 완료·실패 상태와 실패 이유를 표시한다. 상태는 자동으로 다시 확인하며, 저장된 초안을 다시 생성할 수 있다.
- **평가항목·근거:** `∘ 지표명 (5점)`처럼 한 셀에 묶인 지표를 점수별 행으로 나눈다. 제안요청서 파싱 원문에서 지표명과 배점이 일치하는 쪽 번호를 찾아 AI 초안과 검토본의 근거에 표시한다.
- **검토 화면:** `초안 생성`과 `검토 (복사본 고치기)` 메뉴로 자유롭게 이동한다. 검토본이 없으면 기본 서식을 열고, AI 초안은 `AI 초안 반영`을 선택했을 때 검토본에 복사한다. 별도의 돌아가기 버튼과 중복 안내 문구를 제거했다.
