심사임당 · 위원 관리 v2

평가위원 등록과 선정

SQLite에 실제 저장되는 위원 기능입니다. 공통 로그인과 평가 명단 수신은 별도 연결이 필요합니다.

위원 기능 연결

서버 실행 때 생성된 data/web-v2/access-code.txt의 연결 코드를 입력하세요. 기존 웹의 시연 로그인과 별도로 확인합니다.

위원 후보 관리

부서 풀과 사업 직접 등록 명단을 구분합니다.

성명소속전문분야휴대전화상태관리
개별 등록·수정
전문분야 (복수 선택 가능)
엑셀 일괄 등록

양식에 맞춘 XLSX 파일을 확인한 뒤 등록합니다. 오류가 있으면 수정 후 다시 올려 주세요. 최대 8MB·5,000행입니다.

사업별 평가위원 선정

확정 초청 명단을 만든 뒤 평가 담당자에게 전달합니다.

  1. ① 규칙 저장
  2. ② 3배수 선정 / 직접 등록
  3. ③ 연락 결과 확인
  4. ④ 초청 명단 확정
이 사업은 위원 DB에 없습니다. 공통 사업 정보를 연결한 뒤 사용할 수 있습니다. 다른 사업으로 자동 대체하지 않습니다.

1. 선정 규칙

분야별 정원 합계는 정위원 수와 같아야 합니다.

2. 후보 선정

사업별 직접 등록은 규칙 저장 후 후보 관리에서 등록하거나 부서 풀의 ‘사업에 추가’를 사용하세요.

3. 연락 결과와 초청 명단

통화 후 ‘참여 가능’을 저장한 후보만 확정할 수 있습니다. 정위원과 예비 순위를 직접 선택하세요.

성명·소속분야연락 결과통화 메모기록명단 구분예비 순위제외

4. 최종 초청 명단 확정

명단 확정 후 후보·연락 결과·선정 규칙은 잠깁니다. 실제 참석 확인과 위원장 지정은 평가 모듈에서 진행합니다.

최종 명단을 확인하세요

확정하면 명단을 변경할 수 없습니다. 평가 모듈 수신 전까지 ‘수신 대기’로 표시됩니다.
