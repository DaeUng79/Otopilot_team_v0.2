# PM-01 · 코드

| 항목 | 내용 |
|---|---|
| 화면 기획 | [v2/사업담당자/PM-01-사업-목록-등록/](../../../../v2/사업담당자/PM-01-사업-목록-등록/) |
| 팀 버튼 ID | PRJ-01~05, PRJ-08~09 |
| 상태 | 통합 서비스에 연결됨 |

사업목록의 상태 선택은 전체선택·준비·평가·완료·삭제를 제공한다. 삭제를 고르면 `PRJ-08`이 `projects_delete.sqlite3`의 이력을 읽고, 행의 기록 보기는 `PRJ-09`를 사용한다. 다른 부서의 삭제 이력은 서버가 제외한다.

사업 정보 화면의 삭제(`PRJ-04`)는 삭제 사유를 필수로 받는다. 준비 중이며 평가 회차가 없는 사업만 삭제할 수 있다. 사업 정보와 삭제 당시 요구사항 요약을 데이터 폴더의 `projects_delete.sqlite3`에 보관하고 활성 목록에서 숨긴다. 통합 서비스의 위원·평가 외래키와 감사 기록을 유지하기 위해 원본 행과 문서·평가 자료는 물리 삭제하지 않는다. 보관 DB의 전화·이메일은 기존 암호화 키로 암호화해 저장한다.
