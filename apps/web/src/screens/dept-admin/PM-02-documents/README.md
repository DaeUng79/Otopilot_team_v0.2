# PM-02 · 코드

| 팀 버튼 ID | DOC-01~06 · PRJ-06·07 · PRO-01~03 |
| 상태 | 제안요청서 HWPX 업로드·파싱·원본 저장·조회 연결 |

규칙: 이 폴더 파일 맨 위에 `// PM-02 · PRJ-02 · DOC-01·02·04·05·06` 를 적는다. DB 경로나 SQL은 넣지 않고 API(기능 출력 모양)만 쓴다.

제안요청서 파일은 메인 FastAPI의 `POST /api/v2/projects/{id}/rfp`로 전송한다.
파싱 결과와 원본은 `--documents-db`의 SQLite에 저장하고, 평가위원 열람용
문서 버전을 평가 DB에 고정 연결한다. `GET /api/v2/projects/{id}/rfp`로
업로드 이력을 읽고 `/source`, `/download`로 저장된 문단·표 및 원본을 확인한다.
등록 화면의 `제안요청서 확인` 버튼은 담당자 전용
`/app/dept-admin/PM-02/design/rfp-preview.html?project_id={id}`를 연다.
이 화면은 최신 업로드의 고정 파싱 버전을 `/rfp/preview`와
`/rfp/preview/pages/{n}`에서 읽고, `/rfp/preview/pages/{n}/svg`로 원본 쪽을 렌더링한다. 렌더링할 수 없으면 저장된 파싱 내용을 보여준다. 평가위원 EV-03은 별도 로그인과
참석 확인을 요구한다.
업체별 제안서 등록·이력·원본·영구 삭제(PRO-01~03)는 `POST /api/v2/projects/{id}/vendors/{vendor_id}/proposals`, `GET .../proposals`, `.../proposals/{id}/download|source`, `DELETE .../proposals/{id}`로 연결했다. 새 등록은 HWPX·PDF·PPTX만 허용하며 HWP는 화면과 서버에서 거부한다. 제안요청서와 제안서의 삭제는 평가 시작 전 사업에서만 허용하며, 선택한 등록과 전용 분석 데이터를 제거한다. 다른 등록 건이 공유하는 원본은 보존한다. 업체 삭제(PRJ-07)는 같은 제한 아래 업체 ID의 모든 제안서 차수·분석·평가 참조를 영구 삭제한다. 같은 법인명을 다시 등록하면 새 업체 ID가 부여된다. 요구사항 추출 상태·재시도(DOC-03·04)는 `.../requirements`, `.../requirements/jobs`. 목차 수정은 아직 연결되지 않았다.

제안서의 `제안서 보기`는 `/app/dept-admin/PM-02/design/proposal-preview.html?project_id={id}&upload_id={id}`로 이동한다. 제안요청서와 같은 쪽 넘김 화면에서 PDF는 원본을 쪽별 PNG로 렌더링하고, HWPX·HWP는 원본 SVG를 표시한다. 원본 렌더링에 실패하면 저장된 파싱 내용을 표시한다. PPTX는 현재 파싱 내용만 표시한다. PDF 렌더링에는 `PyMuPDF`가 필요하다.

제안요청서를 등록하거나 재등록하면 서버가 요구사항 요약 작업을 자동으로 시작한다. 화면은 작업 상태를 5초 간격으로 갱신하며, 저장과 추출이 모두 성공한 경우에만 `✓ 완료`를 표시한다. API 키·통신·추출 오류가 나면 원본 보존과 실패 이유, 다시 시도 동작을 표시한다. 완료 후 `제안요청서 확인` 버튼이 활성화된다.

삭제된 업체와 같은 이름을 다시 등록하면 기존 업체 ID와 표시 코드를 복원한다. 이전 제안서는 삭제 이력으로 남고, 새 제안서는 같은 업체의 다음 업로드 버전으로 저장된다.

제안요청서 등록 뒤 표시되는 등록 자료·사업 현황·비교 표 영역은 `GET /api/v2/projects/{id}/requirements/proposal-comparison`을 읽는다. 처리 중에는 상태를 보여주고, 추출이 완료되면 사업 현황과 요구사항을 보여준다. 업체별 최신 READY 제안서의 2차 분석 결과를 열로 붙인다. 확인된 제안사항의 원문 근거를 펼치면 제안서 해당 물리 쪽으로 이동한다. 2차 분석이 시작되지 않았거나 일부만 처리된 업체는 처리 상태를 그대로 표시하며, 미처리 항목을 `확인되지 않음`으로 바꾸지 않는다. 검색과 요구사항 구분 필터를 제공한다.
